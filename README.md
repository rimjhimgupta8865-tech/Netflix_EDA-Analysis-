# Netflix_EDA-Analysis-
This project focuses on analyzing the Netflix dataset to understand content trends, distribution patterns, and characteristics of movies and TV shows available on the platform. The analysis involved data cleaning, preprocessing, exploratory data analysis (EDA), and visualization to extract meaningful insights from the dataset.

The project explores key attributes such as content type, title, director, cast, country, date added, release year, rating, duration, and genre. Various analyses were performed to understand the distribution of Movies and TV Shows, content growth over the years, popular genres, country-wise content availability, ratings, and duration patterns.

Python was used for data cleaning, transformation, analysis, and visualization. Libraries such as Pandas, NumPy, Matplotlib, and Seaborn were used to process the data and create informative visualizations.

The project helps identify important content trends and provides a better understanding of Netflix's content library through data-driven analysis. It demonstrates practical skills in data preprocessing, exploratory analysis, visualization, and extracting business-relevant insights from real-world datasets.
